🚀 Key Features of JavaScriptDynamically Typed: You don't need to explicitly declare variable types (like integer or string); JavaScript figures it out at runtime.Interpreted & Just-In-Time Compiled: Browsers read and execute JavaScript code directly without requiring a manual compilation step.Event-Driven: It listens and responds to user behavior, such as button clicks, mouse movements, or keypresses.Asynchronous: It can handle heavy background tasks (like fetching data from an API) without freezing the user interface
